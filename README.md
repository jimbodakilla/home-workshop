# Home Workshop

A small daily workshop page for a young child, built to run on an iPad or phone with no account and nothing to install.

A friendly robot helper offers four stations: **Read**, **Build**, **Explain** and **Numbers**. Each one gives three choices, then one short how-to. Finishing a station earns a star toward a weekly treasure that a grown-up sets. There are 77 activities, shuffled so the same three choices never come back day after day.

- Everything is ordinary reading, vocabulary, building and math. There are no test-style questions.
- Nothing leaves the device. Names, progress and notes are kept in the browser's local storage only, and a grown-up can copy a backup and restore it on another device.
- A press-and-hold gate keeps the grown-up tools (settings, a two-week log, work samples, a message template for the teacher) away from the child.
- Works offline after the first visit and can be added to the Home Screen. Read-aloud, a visual timer and sound are all optional, and animation respects reduced-motion settings.

One HTML file plus a small service worker. No build step, no tracking, no dependencies except the two Google fonts, which are kept after the first visit.
