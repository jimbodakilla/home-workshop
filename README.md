# Home Workshop

A small daily workshop page for a young child, built to run on an iPad or phone with no account and no install.

A friendly robot helper offers four stations: **Read**, **Build**, **Explain** and **Numbers**. Each one gives three choices, then one short how-to. Finishing a station earns a star toward a weekly treasure that a grown-up sets.

- Everything is ordinary reading, vocabulary, building and maths. There are no test-style questions.
- Nothing leaves the device. Names, progress and notes are kept in the browser's local storage only.
- A press-and-hold gate keeps the grown-up tools (settings, a two-week log, a work-sample log, a message template for the teacher) away from the child.
- Visual timer, read-aloud and sound are optional, and animation respects reduced-motion settings.

Open `index.html`, or use the published page. It is a single file with no build step.
